# ctl/

Schedule macro `.ctl` files referenced by `.scd` lines generated by
`whenup.make_sched()`: `SUN_NO_ANT3`, `SUN_ANT3`, `STOW_ANT3` -- the Ant 3
late-start workaround (see the 2026-08-31 History entry in `whenup.py`).
The first SUN scan of the day excludes Ant 3, Ant 3 joins the solar track
once the Sun rises above `ANT3_SUN_LIMIT_DEG`, and Ant 3 is stowed again
once the Sun sets below that limit.

The scheduler opens `<MACRO>.ctl` from `/home/sched/Dropbox/PythonCode/Current`
on helios, so deployment means copying these files there.

IMPORTANT: before deploying, diff `SUN_NO_ANT3.ctl` against the CURRENT
live `SUN.ctl` on helios -- this version derives from the 2026-08-18
snapshot in `debug_tracktables/20260818_20260820/ctl_snapshot/` -- and
re-apply the three ant3 differences if `SUN.ctl` has changed since:
1. `TRACKTABLE sun_tab.radec` gains the explicit list `ant1-2 ant4-15`
   (live SUN.ctl has no antenna argument, i.e. loads all antennas);
2. `TRACK ant1-15` becomes `TRACK ant1-2 ant4-15`;
3. a new `STOW ant3` line is added just before `STOW ant16`.

`SUN_ANT3.ctl` intentionally has no `$SCAN-STOP`/`$SCAN-START`: Ant 3
joins the ongoing scan. See ovsa-ops-memo `docs/reference/ant3-sun-late-start.md`.
